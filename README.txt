# عربی هفتم | ماجراجویی زبان

این نسخه یک وب‌اپ کاملاً استاتیک است:
- بدون بک‌اند
- بدون دیتابیس
- مناسب موبایل و دسکتاپ
- HTML + CSS + JavaScript + JSON
- ذخیره پیشرفت در localStorage
- نقشه مرحله‌ای، XP، نشان، آزمون، بازی، جزوه و قواعد
- پنل مدیریت محلی با کد 59
- ورود/خروجی JSON برای توسعه محتوا

## اجرا
فایل‌ها را در یک پوشه نگه دار:
index.html
style.css
app.js
data.json

برای تست محلی بهتر است با یک static server باز شود. برای آنلاین‌کردن، کل پوشه را روی GitHub Pages یا Cloudflare Pages قرار بده.

## مدیریت
روی «مدیریت» بزن و کد 59 را وارد کن.
توجه: چون سایت بدون بک‌اند است، این رمز امنیت واقعی نیست و داخل کد قابل مشاهده است. تغییرات پنل در همان مرورگر ذخیره می‌شوند. برای انتشار تغییرات برای همه، فایل JSON خروجی را بردار و data.json را روی هاست استاتیک جایگزین کن.

## محتوا
data.json شامل 10 مرحله نمونه و سؤال‌های آموزشی است. برای متن دقیق کتاب درسی، بهتر است محتوای رسمی کتاب خودت را وارد/ویرایش کنی.
