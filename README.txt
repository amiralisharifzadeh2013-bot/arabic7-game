ArabicYar OMEGA — نسخه نهایی استاتیک
========================================
فایل‌ها:
- index.html
- style.css
- app.js
- data.json
- admin.json

ویژگی‌ها:
- ورود دانش‌آموز بدون OTP
- نقشه مراحل، درس‌ها، واژه‌ها، نکته‌ها، قواعد و آزمون
- آرنای Memory / True-False / Combo Boss
- XP، Level، سکه، قلب، رکورد، مأموریت و دستاورد
- فلش‌کارت
- فروشگاه
- پیام دانش‌آموز و پاسخ مدیر روی همان مرورگر
- پنل مدیر با کد 59
- پشتیبان JSON
- طراحی ریسپانسیو و موبایل
- حالت روشن/تاریک
- footer: سازنده: امیرعلی شریف‌زاده

نصب:
1) همه فایل‌ها را در ریشه Repository گیت‌هاب قرار بده.
2) GitHub Pages را روی branch و root همان پوشه تنظیم کن.
3) سایت را refresh کن.

نکته:
GitHub Pages فایل JSON را در مرورگر کاربر به‌صورت write-back ذخیره نمی‌کند؛ state، پیام‌ها و پیشرفت در localStorage مرورگر نگهداری می‌شوند.
